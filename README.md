# ai4r_policy

Student ROS 2 policy package for the DREAM robot. Initial implementation is in
development. `dev` is the active development branch; `main` is the release-ready
line. Immutable version tags identify releases.

Repository conventions follow the [DREAM development guide](https://gitlab.unimelb.edu.au/dream/dream_system/-/blob/main/docs/development-guide.md).
