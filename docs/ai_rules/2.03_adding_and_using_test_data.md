# Adding and using test data

Use this when adding, changing or loading scenario schemas or test data under
`tests/scenarios/`.

## Layout

See `3.00_codebase_structure` for the `tests/` folder map. Keep scenario schemas under
`tests/scenarios/schemas/` and instances under appropriate folders.

## Schemas

- Prefer JSON Schema draft 2020-12.
- Name files `<topic>_data_schema.json`.
- Each topic may define its own format. Do not assume one shared scenario shape
  across schemas.
- Keep each schema accurate for its topic; update it when that topic's data
  contract changes.

## Using test data

- Ideally load scenario instances from `tests/scenarios/`, not from ad-hoc dicts in test
  code, when a schema already covers the case.
- Validate loaded JSON against the schema for that topic before using it in a
  test.
