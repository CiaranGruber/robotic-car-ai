# Coding standards

- When you add a new Python package dependency, list it in `requirements.txt`. For custom wheels
  that are not on PyPI, follow `2.04_managing_wheel_files`.
- Put test code that is not only meant to run on the car in `tests/policy/`.
- When you add a file or folder that must not be uploaded to the car, add an rsync
  filter rule in `car_upload_filter.txt` (see that file's comments for `+` / `-`).
- For a parameter whose type is a dataclass (especially a simple structural one), keep its docstring
  generic. Do not list or explain that type's fields; those can change.
- Use the standard `logging` module. In each module that logs, define
  `_LOGGER = logging.getLogger(__name__)` and log through `_LOGGER`.
