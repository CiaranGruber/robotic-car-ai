# Basic codebase rules

- When you add a new Python package dependency, list it in `requirements.txt`. Custom wheels
  that are not on PyPI go in `wheels/` so they can be installed with the CI (see that folder's README).
- Put test code that is not only meant to run on the car in `tests/policy/`.
- When you add a file or folder that must not be uploaded to the car, list it in
  `files_not_to_upload.txt`.
