# Car memory

Store data that must last across policy steps on `Memory` in `policy/memory.py`. Read it with
`CarMemory.data`. Add further memory as fields of `Memory`. Each field must serialise and
deserialise, as the types in `policy/input_output.py` do.

Change memory only inside `CarMemory`:

- Add a method for each change, such as `step()` for the policy step count.
