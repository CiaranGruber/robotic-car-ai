# Managing wheel files

Use this when adding, changing, installing or removing custom Python wheels under `wheels/`.

## What belongs in `wheels/`

- Put custom Python wheels that are not on PyPI in `wheels/` (for example `dreamgym-*.whl`).
- Keep PyPI packages in `requirements.txt` as installable lines (see `0.01_coding_standards`).
  Do not add wheel-only packages as active `requirements.txt` lines; the file may note their
  version in a comment, as with dreamgym.

## Installing

Install PyPI packages first, then any vendored wheels:

```bash
pip install -r requirements.txt
pip install wheels/*.whl
```

CI follows the same order and installs `wheels/*.whl` when any `.whl` files are present.
