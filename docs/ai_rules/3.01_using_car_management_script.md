# Using the car management script

Use `scripts/car_management.sh` to upload this package, build on the car, or restart dream
runtime services. Set `CAR_NUM` in the script first. Ask the user before running any command
that contacts the car. For commands and options, run `help` or read the script.

`car_upload_filter.txt` holds rsync filter rules for what is not copied to the car (see also
`0.01_coding_standards`). Before any real upload (`upload` or `upload_and_build`), run
`dry_copy` and check the listed files. If something looks like it should not go to the car,
ask the user and, if they agree, add a rule to `car_upload_filter.txt` before uploading.
